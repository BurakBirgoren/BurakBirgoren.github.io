Building Resilient Generative Response Networks

我们构建生成式人工智能系统：即使某个部分失效，系统仍能持续响应。

什么是高韧性系统？

无论是语言、语音、图像还是预测，我们对每个项目都坚持四点。

  • 备用路径

    主模型响应变慢或宕机时，请求会转到备用模型，用户不会看到错误。

  • 置信度阈值

    模型没有把握时不会猜测，而是标明不确定性，或将任务交给人工处理。

  • 上线前评测

    每次改动都在固定测试集上评测；结果变差就不上线。

  • 数据不出内网

    数据敏感时，模型部署在机构自有的服务器上，数据不外流。

技术能力

我们从事的技术方向。

  • 智能体系统

    分工明确的多智能体团队；负责规划、执行与审核的智能体；可无人值守运行长任务的工作流。

  • 企业搜索与 RAG

    文档切分、向量化与检索；回答附带来源；翻译与摘要。

  • 语音识别与听写

    识别领域术语的语音识别；确定性术语词典；实时文本纠正。

  • 语音助手

    通过对话完成事务的助手：语音识别、对话管理与语音合成一体化。

  • 对话分析

    录音转写、说话人识别；提取摘要、决议与待办事项。

  • 文档理解与 OCR

    用视觉语言模型读取扫描文档；字段抽取；基于规则的自动核查。

  • 图像理解

    分类、分割，以及基于深度数据的尺寸估计。

  • 图像与视频生成

    保持身份一致的图像生成、会说话的数字人、语音合成。

  • 决策支持与优化

    基于规则与约束的优化引擎；由语言模型解释每个结果的依据。

  • 模型适配

    LoRA 微调；领域词典与确定性纠错层。

  • 模型部署与基础设施

    在本地 GPU 上运行开源模型：vLLM、并发与内存调优、带密钥的 API 网关。

  • 移动端与边缘设备

    在手机和边缘设备上运行模型的应用。

输入什么，输出什么？

输入语音、文档、图像、文本或数据；输出转写、摘要、回答、决策或图像。
